# Adhishri Deshmukh - Portfolio (React JS + Vite + Tailwind CSS + Framer Motion)

Live: https://adhishri123.github.io

## Run locally
```
npm install
npm run dev        # http://localhost:5173/
npm run build
npm run preview
```

## Edit your content
Only one file: `src/data/index.js`.

## Deploy
Every `git push` to `main` runs `.github/workflows/deploy.yml` and publishes the site to GitHub Pages.

The base path is read from the repo name automatically, so renaming the repo needs no code change.
